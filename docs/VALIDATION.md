## 如实说明的边界

- 尚未在其他实体电脑、所有 Windows 版本、所有 DPI / 输入法组合上进行测试；未做代码签名。
- GUI 测试覆盖关键流程，但不是所有鼠标操作的逐项人工验收。
- 未做真实断电、硬件损坏或 100 MB 极限数据压力测试；异常退出测试针对未提交事务。
- 没有在线同步、自动定时备份、拼音排序、模糊号码标准化或加密功能。它们不以空按钮或伪实现存在。
- 事务仍采用完整快照。保存与文件操作已放到独立线程，但初次打开数据库、图片选择处理和大量控件/图表渲染仍有主线程开销；未验证极限规模性能。真实复杂度在架构文档中公开说明。
